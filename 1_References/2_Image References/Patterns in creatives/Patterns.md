# Patterns in Creatives

Pattern work must stay inside the locked brand frame.
Do not use motif changes as a way to introduce new typography, layout, or color systems.

Use this skill for the recurring visual grammar behind the repo's marketing creatives.
It defines how motifs scale, where they sit, and how they support the headline and hero without flattening the frame.

When a slide includes the Cars24 logo, read `2_Image references/Logos/README.md` and `2_Image references/Logos/logo-types.md` first. Motifs must not intrude on logo clear space or reduce lockup contrast.

## What This Skill Covers

- repeatable motif families
- motif scale and density
- placement and framing rules
- how patterns support hierarchy
- what to avoid so the composition stays premium

## Core Layout Pattern

- one dominant headline
- one primary hero
- one supporting motif field
- readable supporting text
- strong negative space
- for carousels, keep the same brand system, typography, theme, and pattern vocabulary, but rotate layout archetypes and vertical anchors so consecutive slides do not repeat the same structure by default
- keep a clean logo placement area (usually a corner) when the Cars24 lockup is present; keep wave fields and halos from bleeding into that area
- do not use subject or motif changes as a substitute for real layout selection; if several slides share the same structure, the reason should be intentional and visible in the layout plan
- negative space should be used for a complete text hierarchy, not left empty by default

## Composition Rules

- headline can lead from the top, bottom, centre, or full canvas depending on the selected archetype
- hero can live centre-lower, right, lower-right, or be absent entirely depending on the selected archetype
- motif often forms a bottom base, edge frame, or halo
- keep the visual hierarchy simple and fast to read
- let the motif support the composition instead of becoming the composition
- when the copy block grows larger for legibility, reduce motif density behind it rather than shrinking the type
- motifs should frame and energize the text block, not compete with readable subtext

## Pattern Families

The reference set repeats a small number of motif families rather than random decoration.

### 1. Wave Field

- halftone or point-cloud waves
- flowing dot curtains
- curved mesh surfaces
- topographic or terrain-like undulations
- useful when the layout needs motion, depth, and a directional sweep

### 2. Shell Halo

- spherical or partial-spherical light shells
- bright arcs wrapping around a volume
- halo rings behind a hero or type block
- useful when the layout needs a central anchor and a strong sense of energy

### 3. Edge Frame

- rounded-corner glow frames
- corner-driven luminous borders
- diagonal edge sweeps that pull the eye inward
- useful when the motif should contain the subject without boxing it in

### 4. Particle Bloom

- soft particle clusters
- bokeh-like glows
- perimeter spark fields
- atmospheric drift around the main motif
- useful for adding aura, depth, and a launch-like finish

### 5. Gradient Atmosphere

- violet-to-blue washes
- pale editorial fields in the light set
- soft blooms that move the eye without drawing attention from the hero
- useful as the base layer under all other motifs

### 6. Organic Mesh

- wrapped or folded point fields
- elastic-looking surface distortions
- liquid cloth or membrane-like waves
- useful when the composition needs a more tactile or sculptural feel

## Scale

Use one dominant scale per composition so the frame feels intentional.

- micro scale: sparse particles, fine dot haze, light perimeter glow
- mid scale: the default mode for most posters, with readable wave fields and halo structures
- large scale: broad luminous sweeps, oversized arcs, and shell-like fields for open hero-led compositions
- full-frame scale: a pattern becomes the scene itself, used only when the headline is very minimal
- pair a primary scale with at most one secondary scale
- match smaller motif scales to dense headlines and larger scales to open, launch-like layouts
- let the pattern taper off at the edges instead of repeating uniformly across the whole frame
- use the smallest effective motif scale first; increase it only when the slide needs more energy

## Placement

- often anchored at the bottom edge
- sometimes used as a halo behind the hero
- sometimes used as a structural base for the composition
- sometimes wrapped around a corner or edge to create a frame
- sometimes used as a directional sweep from lower-left to upper-right
- the motif should feel like energy or atmosphere, not a decorative wallpaper
- the motif can spill beyond the frame edges so it feels spatial rather than boxed in
- not every slide needs a large pattern field; many slides will read better with only a faint halo or no visible motif at all
- the motif must never become the primary information container; do not use it to replace human-led scenes with cards, charts, or infographic panels

## Scale And Placement Pairing

- micro scale works best as edge haze, spark fields, or a subtle halo
- mid scale works best as a bottom base, halo ring, or side swell
- large scale works best as a hero-backed shell, sweeping field, or partial frame
- full-frame scale works best when the pattern is the primary visual and the text is minimal
- avoid mixing multiple large-scale pattern families in the same frame

## Pattern Rules

- keep the motif subtle and repeatable
- avoid busy texture or random ornament
- use the pattern to support depth, motion, and energy
- let the pattern fade out cleanly at the edges instead of filling every corner
- the pattern should help the hero and headline feel more grounded
- prefer layered transparency, soft blur, luminous overlays, and blend-driven glow over hard-edged ornament
- use patterns sparingly in multi-slide sets
- if a subject already carries the slide, reduce the motif rather than increasing it
- if a slide is about a strong statement or closing line, a lighter motif is usually enough
- if a slide feels empty, solve the information hierarchy first with larger hero/subtext treatment; do not use motifs as filler
- keep motif contrast lower behind Geist supporting copy so the subtext stays readable at carousel scale

## What To Avoid

- cluttered multi-panel layouts unless explicitly needed
- decorative textures with no structural role
- multiple competing focal points
- symmetrical layouts that flatten the energy
- flat empty backgrounds without some kind of atmospheric field or glow
- repeating the same motif at the same intensity everywhere
- mixing too many motif families in one composition
- filling every slide with the same pattern treatment
- running dot-wave, halo, or edge-frame motifs through the logo clear space
- placing a primary purple logo on a brand-violet field (use inverted white lockup instead)
- drifting away from the reference palettes, motif density, or spacing language; use the supplied references as the ceiling, not just a loose inspiration
- using pattern variation to justify changes to typography, layout, or color rules

## Quick Decision Flow

1. Decide the hero's position.
2. Decide whether the headline needs a dense or open frame.
3. Pick the motif family that best supports that hierarchy.
4. Choose the scale: micro, mid, large, or full-frame.
5. Decide where the motif should live: base, halo, edge, sweep, or full field.
6. Fade it off the edges so the composition feels designed, not tiled.

## Pattern Generation Prompt Formula

Use this formula when generating a pattern reference or motif asset:

`generative pattern, [motif family] emerging from [atmosphere or field], [transformation action], [core material] made from [dot / point / particle structure], [depth treatment], [rim glow or halo treatment], [density and perspective behavior], [foreground and background particle treatment], [scale choice], [negative space choice], [palette / theme], [aesthetic finish]`

### Prompt Slots

- `[motif family]`: wave field, shell halo, edge frame, particle bloom, gradient atmosphere, or organic mesh
- `[atmosphere or field]`: code, haze, void, glow field, editorial field, or launch field
- `[transformation action]`: emerging, wrapping, analyzing, transforming, unfolding, or orbiting
- `[core material]`: holographic projection, luminous shell, point-cloud surface, or layered glow structure
- `[dot / point / particle structure]`: tiny white dots, fine point mesh, particle clusters, or dense dot matrix
- `[depth treatment]`: macro-photographic shallow depth of field, layered perspective, or soft spatial falloff
- `[rim glow or halo treatment]`: soft rim glow, luminous outline, halo ring, or edge bloom
- `[density and perspective behavior]`: dense in the focal plane, variable dot sizes, or perspective falloff toward the edges
- `[foreground and background particle treatment]`: blurred circular bokeh, drifting particles, or soft particle bloom
- `[scale choice]`: micro scale, mid scale, large scale, or full-frame scale
- `[negative space choice]`: open negative space, strong void, edge fade, or minimal field
- `[palette / theme]`: monochrome black and white, blue-violet editorial, pale lavender, or saturated electric violet
- `[aesthetic finish]`: minimalist, cinematic abstract technology aesthetic, luminous editorial aesthetic, or premium launch visual

## Pattern Overlay System

> How to apply any pattern from this library onto a generated HTML creative.

All 13 patterns can be used as CSS overlay layers using blend modes. No Photoshop needed — the pattern's background colour disappears through blending, leaving only the dot motif visible on top of your canvas.

### CSS File

```
1_References/2_Image References/Patterns in creatives/pattern-overlay-system.css
```

Link it in any creative HTML from `4_exports/`:
```html
<link rel="stylesheet"
      href="../1_References/2_Image References/Patterns in creatives/pattern-overlay-system.css">
```

### How to Use — Three Modifier Classes

```html
<div class="c24-pattern  [theme]  [placement]  [pattern-name]"></div>
```

The parent container must be `position: relative; overflow: hidden`.

**Theme** (sets blend mode + opacity):
| Class | Blend mode | Use on |
|---|---|---|
| `c24-pattern--dark` | screen, 0.8 | Brand Blue `#4736FE` backgrounds |
| `c24-pattern--light` | multiply, 0.65 | Pale lavender `#EEEFFE` or white |

**Placement** (positions the pattern div):
| Class | Position | Default use |
|---|---|---|
| `c24-pattern--bottom-right` | Bottom-right corner, 65% size | Most dark hero posts |
| `c24-pattern--centre` | Centred, 72% size | Logo identity, stingers |
| `c24-pattern--full-bleed` | Full canvas | Text-only posts |
| `c24-pattern--right-side` | Right half, contain | Side accent |
| `c24-pattern--left-side` | Left half, contain | Reverse accent |
| `c24-pattern--bottom-centre` | Bottom-centre, 90% wide | Dome anchor |
| `c24-pattern--bottom-edge` | Full-width bottom strip | Low sweep |

**Optional scale overrides:**
- `c24-pattern--micro` — pulls opacity to 0.35, use behind dense copy
- `c24-pattern--large` — expands the placement zone, use for open hero layouts

### Layer Stack in HTML

```html
<div class="creative" style="position:relative; overflow:hidden; background:#4736FE;">
  <!-- Layer 1: background (set above) -->
  <!-- Layer 2: illustration PNG  z-index: 1 -->
  <!-- Layer 3: pattern overlay   z-index: 10 (auto via .c24-pattern) -->
  <!-- Layer 4: text / copy       z-index: 20+ -->
  <div class="c24-pattern c24-pattern--dark c24-pattern--bottom-right c24-pattern--mountain"></div>
</div>
```
