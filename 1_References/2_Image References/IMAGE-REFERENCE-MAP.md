# Image Reference Map

> Source of truth for selecting templates, characters, and background patterns when creating posts or image briefs.
> All files live in `1_References/2_Image References/` and `1_References/3_Illustrations References/`.

> **Composition reference only.** The dark/light theme card examples in this document (Sections 1–2) show layout structures — headline position, pattern placement, safe zones, and hierarchy. They are not style targets. All generated visual content must follow the Cars24 brand book: photography or modern sleek flat-editorial illustrations with South Asian characters rendered inside the final themed composite. See `master-rules.md` → Visual System Boundaries.
>
> **v2.0 tagging layer:** use `../reference-index.json` and `../reference-tags/` before selecting references. The map below describes what appears in each file; the tag layer decides what to copy and what to ignore.
>
> **Marble/statue guard:** if a theme reference contains a marble/statue hero, treat that subject as a layout placeholder only. Do not generate marble/statue photo heroes. For photo output, use real humans, real cars, real hubs, or real Cars24 service moments.

## 5. Quick Selection Guide

### "What template should I use?"

| Content Goal | Theme | Format | Layout Template |
|---|---|---|---|
| Campaign opener / series cover | Dark | 4:5 | DT-1 |
| Brand statement (no figure needed) | Dark | 4:5 | DT-6 |
| Relatable pain-point / humour | Dark | 4:5 | DT-2 or DT-9 |
| Newsletter subscribe promo | Dark | 4:5 | DT-7 |
| Value/outcome reveal | Dark | 4:5 | DT-5 |
| Instagram square — opener | Light | 1:1 | LT-1 |
| Instagram square — relatable | Light | 1:1 | LT-2 or LT-3 |
| Thought leadership | Light | 1:1 | LT-5 |
| Recruitment / community post | Light | 1:1 | LT-7 |
| Event / deadline ad | Dark | 4:5 | DT-3 |

### "What illustration should I use?"

| Scenario | Illustration |
|---|---|
| Female solo, aspirational | `Frame 2147228886.png` |
| Driving confidence / interior POV | `freepik ...75907... [Vectorized]-1.png` |
| Freedom / open road | `Frame 2147228890.png` |
| Two people / handover scene | `freepik ...75910... [Vectorized].png` |
| Brand panorama / campaign / family story | `Group.png` |

### "What pattern should I use?"

| Scenario | Pattern |
|---|---|
| Hero-led dark post | `mountain pattern dark theme.png` or `large circle pattern dark theme.png` |
| Logo identity / stinger | `Centre pattern dark thme.png` |
| Text-only dark post | `full bleed pattern dark theme.png` |
| Hero-led light post | `Side Pattern light theme.png` or `Circle pattern bottom light theme.png` |
| Text-only light post | `Full bleed pattern light theme.png` |
| Side-accented composition | `side pattern dark theme.png` or `Side Pattern light theme.png` |
