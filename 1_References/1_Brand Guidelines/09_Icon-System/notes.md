# Theme 09 — Icon System
> Vision-verified 2026-05-31 — entries below reflect the actual section images.

The Cars24 icon system runs **two parallel families**, both generated via Custom GPT tools rather than styled by hand. Goal stated in the overview: "visual consistency, scalability, and speed across all product and marketing use cases."

- **3D Icons** — rich, product-level visuals with depth (hero, marketing, feature callouts)
- **Flat Filled Icons** — UI, dashboards, lightweight / dense usage

**Core Principles (verbatim from the overview slide):**
- Consistency over creativity
- Simplicity in concept and execution
- Controlled use of color and detail
- Use GPT tools instead of manual styling

## Image: `03_3d-icon-generator.png` — 3D Icon Generator

Left column title "3D Icon Generator" with a purple "Custom GPT Link" button. Right side repeats the same 12 3D icons from the overview, plus a screenshot of the Custom GPT ("Minimal realism 3D icons") generating the number-plate-with-magnifier icon from the prompt **"number plate check"** — output rendered on a plain white square canvas.

**When to use:** Product features and highlights · Marketing visuals and landing pages · Illustrative UI moments.

**Usage Guidelines:**
- Use simple subjects (e.g., car, bank, shield)
- Keep icons to 1–2 elements
- Avoid long descriptive prompts
- Do not request realism or cinematic effects

**Visual Rules:**
- Moderate 3D realism (NOT photoreal)
- Consistent blue-based color system
- Crisp highlights and controlled shadows
- No micro-details or complex internals

**Image-gen prompt notes:** soft studio lighting, gentle glossy plastic/clay-like surfaces, rounded forms, single light source giving a soft shadow underneath, isolated on white/transparent. Accent colors stay limited (gold, green check, red ribbon) over a dominant Cars24 blue. The GPT canvas observed is a 1:1 white square.

**When to use:** Product UI (menus, buttons, dashboards) · Small-size icons · High-density layouts.

**Usage Guidelines:**
- Use single-object concepts
- Keep shapes bold and simple
- Avoid gradients and depth
- Maintain consistency across icons

**Visual Rules:**
- Flat filled style (no 3D or shadows)
- Solid brand colors only
- High contrast for readability
- No decorative elements

**Image-gen prompt notes:** one solid fill color (brand blue/indigo), bold simplified geometry, filled silhouette (not outline-stroke), closed compact forms, even weight, readable at small sizes, isolated on white/transparent. One concept per icon.

## 3D vs Flat — quick reference

| | 3D Icons | Flat Icons |
|---|---|---|
| Use | Hero, marketing, feature highlights | UI, dashboards, dense layouts |
| Color | Blue-dominant + limited accents (gold/green/red/white) | Single solid brand blue |
| Depth | Moderate realism, gloss, soft shadow | None — flat fill, no shadow |
| Detail | 1–2 elements, no micro-detail | Single object, bold simple shapes |
| Source | "Minimal realism 3D icons" Custom GPT | "Cars24 icon generator v1" Custom GPT |

## Creative Direction Insight
The dual system encodes a hierarchy: 3D icons carry attention and product depth (hero / feature callouts); flat icons support scanning and reduce cognitive load (navigation, listings). 3D icons read as a trustworthy, lightly playful app-icon aesthetic anchored in Cars24 blue; flat icons are silent functional workers. For both, prefer GPT generation over manual drawing to keep the family coherent at scale.
