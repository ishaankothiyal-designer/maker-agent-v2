# Theme 03 — Typography
> Vision-verified 2026-05-31 — entries below reflect the actual section images.

## Typeface roles (the one thing to get right)
- **Care Sans** — the brand's custom **geometric sans-serif LOGO typeface**. Used for the **logo / wordmark and select brand lockups only**. It is a signature, NOT a system font. **Never** used for post headlines, body, UI labels, or buttons.
- **Geist** (Geist Sans) — the **primary sans-serif**. Used for headlines, subheads, body copy, logos/large displays, and UI. This is the everyday workhorse type.
- **Arapey** — the **serif** reserved for campaign / editorial headlines and emotive key words. Files present in `fonts/` (`Arapey-Regular.ttf`, `Arapey-Italic.ttf`). Note: Arapey does **not** appear on any specimen page in this section; its role is inferred from the font files + brand system, not shown in these images. Where it IS shown in use: the "Out of Tokens" dark-theme reference creatives (`2_Image References/Dark theme/`) and the rules in `1_References/CREATIVE-DIRECTION.md` (dark headline = Arapey serif italic on emotive words). Never use Arapey for body, subheads, UI labels, or buttons.

## Type-setting rules (consolidated)
- **Case:** Always sentence case. No all-caps for general copy. Title case only for blog titles.
- **Alignment:** Left-aligned OR centered only. Never justified, never right-aligned.
- **Lockup:** "Better drives, better lives." is a pre-set asset (stacked or single-line). Do not retype, restyle, re-kern, or recolor. Drop it in as supplied.

## Weight pairing system (from `07`)
| Pairing | Use / tone |
|---|---|
| Bold / Light | Standard hierarchy (key message over subheader) |
| Black / Medium | High-impact, heavy contrast |
| Bold / Regular italic | Eyebrow over emotive key message |
| Medium italic / Black | Eyebrow over product-led key message |

**Avoid:** Medium/Regular and Bold/Light-too-close combinations — i.e. avoid pairing weights that sit adjacent on the scale (the page calls out "Medium/Regular or Bold/Light" as combinations to avoid).

## Quick reference for image-gen / design prompts
- **Logo / wordmark / sub-brand lockup →** Care Sans (geometric sans), used sparingly, always with the CARS24 mark, no effects/distortion.
- **Headlines, subheads, body, UI →** Geist (sans-serif). Pair weights for hierarchy.
- **Campaign / editorial emotive headline →** Arapey (serif), Italic for emotive tone — not shown on these specimen pages but present in `fonts/`.
- **"Better drives, better lives." →** drop in the pre-set Geist lockup (2-line or single-line); never rebuild it.
