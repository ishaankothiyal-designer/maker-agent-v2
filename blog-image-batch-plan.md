# Cars24 Autonauts blog image batch plan

Purpose: source-of-truth planning table for batch publishing blog images.

## Global production defaults

| Field | Default |
|---|---|
| Image dimensions | 1000 x 650 px |
| Image theme | Dark Cars24 brand blue |
| Visible text inside image | Blog title only |
| Blog description | Planning and prompt context only |
| Logo | Not included by default; decide per batch if needed |
| Proper noun/logo/person context | If a blog title or description names a specific company, product, framework, rating system, technology, or person, carry that name into the prompt context. Use the official logo, visual mark, or real person likeness only when it is important to comprehension and an approved reference asset is available; otherwise represent the concept abstractly. |
| Illustration source | All illustrated hero work must use `1_References/3_Illustrations References/` as the style source. `Main_reference.png` is the mandatory primary style anchor; choose one supplement only when the scene needs it. |
| Typography | Sentence case, refined editorial serif headline, key word may be italicised |
| Pattern | Subtle luminous Cars24 atmospheric pattern, behind text and hero only |
| Hero framing | Fully contained; no cropped heads, hands, cars, icons, or key objects |
| Photo treatment | Clean cutout subject with visible white accent outline |
| Do not include | Extra body copy, fake logo, title case, generic navy/purple drift, crowded UI text |

## Open decisions to freeze before prompt assembly

| Decision | Working default | Why it matters |
|---|---|---|
| Logo usage | None by default | Avoids logo hallucination and keeps blog covers editorial unless brand lockup is required |
| Title rewriting | Keep supplied blog title, sentence-case if needed | Keeps article mapping exact while respecting creative case rules |
| Description visibility | Not visible | Prevents crowded covers; description remains prompt context |
| Person likenesses | Avoid likeness unless a real approved photo exists | Prevents accidental inaccurate people images; named people like Gajendra Jangid should be handled through abstract transition imagery unless a reference photo is supplied |
| Third-party logos | Avoid unless approved | Cloudflare, Rive, OpenAI/Whisper, Bharat NCAP marks should not be fabricated |
| Proper noun context | Include named people, companies, products, frameworks, tools, and rating systems in prompt context | Named entities like Gajendra Jangid, Cloudflare Workers, Gupshup, Whisper, OpenAI, Rive, Bharat NCAP, Orbit, and Cars24 Labs shape the correct visual metaphor |
| Batch size for generation | 10 per batch, with first 3 as style check | Reduces risk before producing all 50 |
| Reference selection | Use dark theme, pattern, hero-type, and icon/illustration references per row | Keeps generation consistent with Maker reference workflow |
